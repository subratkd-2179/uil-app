## 🚀 Quick Start (Choose One)

### **Option 1: Fastest Way (2 clicks, 5 minutes)**

1. Open Command Prompt/PowerShell in `c:\UIL APP`
2. Double-click `START_SERVER.bat`
3. Open `UI/uil-tutor-ai.html` in browser

Done! ✅

### **Option 2: Manual Setup (Follow steps)**

1. Open Command Prompt:
   ```bash
   cd c:\UIL APP\API
   pip install -r requirements.txt
   python app.py
   ```

2. In browser, open:
   ```
   c:\UIL APP\UI\uil-tutor-ai.html
   ```

3. Application loads instantly ✅

### **Option 3: Docker Deployment**

```bash
cd c:\UIL APP
docker-compose up
```

Open `http://localhost:5000` in browser ✅
